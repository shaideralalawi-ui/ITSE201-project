# UOB Library — GitHub Pages

The docs folder contains the static site. GitHub Pages is configured to publish from the main branch and /docs folder.

The animated presentation opens at the site home page. The student app sample is available at /app/, and the slides are also available at /slides/.

To publish changes, commit them and push to main. GitHub Pages will rebuild the site automatically. The sample is front-end only; sign-in, borrowing, reservations, fines, and member records are not connected to a backend or database.

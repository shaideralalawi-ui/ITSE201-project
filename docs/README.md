# UOB Library — GitHub Pages

This `docs` folder is the static version of the sample app and scenario slides. It can be published by GitHub Pages without running a Go server. In GitHub, open the repository Settings → Pages, select “Deploy from a branch”, choose the `main` branch and `/docs` folder, then save. GitHub will publish the site URL shown in Pages settings.

The sample app is front-end only: book search, display theme, and demo buttons run in the browser. Borrowing, reservations, sign-in, and member records are not connected to a backend or database.
